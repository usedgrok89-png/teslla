# جدول العيلة

منظم مواعيد أطفال للأب والأم — تطبيق أندرويد عربي بالكامل، بحجم **50 كيلوبايت**.

## ليه صغير أوي؟

- Java خالص، **بدون أي مكتبة خارجية**: لا AndroidX ولا Material ولا Kotlin.
- مفيش `gradle` ولا شبكة: البناء بـ `aapt2` + `javac` + `R8` + `apksigner` مباشرة.
- الأيقونات مولّدة من كود بايثون (`tools/`) كـ PNG صغير.
- `classes.dex` صغير بعد الـ R8 shrinking.

## المميزات

- أطفال بألوان، وفلترة لكل طفل.
- مواعيد: عنوان، طفل، تاريخ، وقت، ملاحظة، وقت التنبيه.
- تجميع المواعيد حسب اليوم: `اليوم` / `بكرة` / `بعد بكرة` / اسم اليوم والتاريخ، وقسم `مواعيد فاتت`.
- **تنبيه فعلي** قبل الموعد (مفيش تنبيه / 5 / 10 / 15 / 30 دقيقة / ساعة / ساعتين / يوم).
- ضغطة على الموعد تفتحه للتعديل، ودائرة الصح تسجّله كـ"تمت".
- ضغط مطوّل على الموعد: تعديل / تم / تأجيل لبكرة / حذف.
- التنبيهات بترجع تشتغل لوحدها بعد إعادة تشغيل الموبايل.
- البيانات محفوظة محلياً (من غير إنترنت ومن غير حساب).

## البناء

محتاج JDK 17 + Android SDK (build-tools 34.0.0 و platform android-34).

```bash
export ANDROID_SDK_ROOT=/path/to/android-sdk
./build.sh
```

اللي بيطلع: `app-release.apk`

مفتاح التوقيع موجود في `release.keystore` (كلمة السر `family2024`) — **احتفظ بيه**، لو ضاع مش هتقدر تنشر تحديث للبرنامج لأن أي مفتاح جديد بيتعامل معاه أندرويد كتطبيق مختلف.

## التركيب على التليفون

```bash
adb install -r app-release.apk
```

أو: انقل `app-release.apk` للتليفون، افتحه من مدير الملفات، وفعّل "السماح من مصادر غير معروفة" لما يطلب منك.

بعد أول تشغيل اسمح بالإشعارات، ولو الجهاز رفض إذن المنبهات الدقيقة فعّله من إعدادات النظام — ده اللي بيخلي التنبيه يطلع في الوقت بالظبط.

## الملفات

```
AndroidManifest.xml
build.sh                     البناء
proguard-rules.pro           قواعد R8
res/                         الموارد (واجهات + ألوان + أيقونات)
src/com/family/schedule/
    MainActivity.java        الشاشة الرئيسية والقائمة والأطفال
    EditActivity.java        إضافة/تعديل موعد
    Data.java                التخزين (JSON في SharedPreferences)
    Reminders.java           جدولة المنبهات
    NotifyReceiver.java      الإشعار
    BootReceiver.java        إعادة الجدولة بعد إعادة التشغيل
    Fmt.java                 تنسيق التواريخ والأوقات بالعربي
tools/make_icons.py          توليد أيقونات المشغّل
tools/make_stat_icon.py      توليد أيقونة الإشعار
```

## ملاحظات

- `android.permission.USE_EXACT_ALARM` موجودة عشان التنبيه يطلع في الوقت بالظبط. لو ناوي ترفعه على Google Play هتحتاج توضّح سببها في Policy Center.
- كل واحد بيحتفظ بجدوله على موبايله (مفيش مزامنة بين الأب والأم).
- الحد الأدنى أندرويد 5.0 (API 21).
